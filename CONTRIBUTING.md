# Contributing

This is an assessed group project. Contributions should follow the approved team workflow and lecturer's assessment rules.

1. Confirm that the project manager/integration lead has approved the change.
2. Create a feature branch; do not edit the deployed production configuration without authorisation.
3. Explain which APEX page, Oracle object, Infobip dialog or Zapier step the change affects.
4. Test changes using synthetic customer data; include steps to reproduce and rollback notes.
5. Open a pull request or the team's agreed review channel and obtain review before merging.
6. Never commit credentials, private REST routes, webhook URLs or client data.

For bug reports include a problem summary, expected/actual result, safe screenshots (redacted), environment and steps to reproduce. Never paste credentials into GitHub issues.
